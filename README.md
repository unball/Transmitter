## Requisitos

- ESP-IDF
- Alguma distro linux para desenvolvimento

> Para baixar e configurar o ESP-IDF, você já baixa todas as outras dependências que precisamos para desenvolver neste repositório. Então, nem citarei as outras dependências. Para baixar o ESP-IDF, [entre aqui](https://docs.espressif.com/projects/esp-idf/en/latest/esp32/get-started/linux-setup.html)

## Observações

- Adicione seu usuário ao grupo dialout ou uucp (depende da sua distro) para conseguir ler e escrever em portas seriais
- Se você usa ubuntu, desative o braille terminal com:

```bash
sudo apt-get remove --auto-remove brltty
```
